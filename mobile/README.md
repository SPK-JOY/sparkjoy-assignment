# Flutter Technical Assignment

## วัตถุประสงค์

แบบทดสอบนี้มีไว้เพื่อให้เราได้เห็นแนวทางการพัฒนา Flutter ของผู้สมัคร ทั้งในด้านการออกแบบโครงสร้างโปรเจกต์ การจัดการ State และคุณภาพของโค้ด ไม่มีคำตอบที่ถูกหรือผิดเพียงแบบเดียว เราให้ความสำคัญกับแนวคิดและเหตุผลในการออกแบบมากกว่าการทำฟีเจอร์ให้ครบทุกอย่าง

---

## โจทย์

พัฒนาแอปพลิเคชันตามข้อกำหนดด้านล่าง โดยสามารถเลือกใช้ Architecture, State Management และ Package ต่าง ๆ ได้ตามความเหมาะสม

### 1. Login (Mock)

สร้างหน้าสำหรับเข้าสู่ระบบ โดย **ไม่จำเป็นต้องเชื่อมต่อ API**

* มีช่อง Email และ Password
* ตรวจสอบข้อมูลเบื้องต้น (Validation)
* เมื่อ Login สำเร็จ ให้จัดเก็บสถานะการเข้าสู่ระบบด้วย State Management ที่เลือก

### 2. Product List

ดึงข้อมูลรายการสินค้าจาก API ที่กำหนด และแสดงผลเป็นรายการ

* แสดง Loading State
* แสดง Error State
* แสดง Empty State
* รองรับ Pull to Refresh

### 3. Product Detail

เมื่อเลือกสินค้า ให้แสดงรายละเอียดของสินค้า เช่น

* รูปภาพ
* ชื่อสินค้า
* รายละเอียด
* ราคา
* หมวดหมู่
* หรือรายละเอียดอื่นๆตาม API สามารถทำได้อย่างอิสระ

## ข้อกำหนดทางเทคนิค

* สามารถเลือกใช้ State Management ได้อย่างอิสระ
* สามารถเลือกใช้ Architecture ได้ตามความเหมาะสม
* สามารถเลือกใช้ Package ต่าง ๆ ได้ตามความเหมาะสม
* คำนึงถึงการแยกความรับผิดชอบของแต่ละ Layer และความสามารถในการดูแลรักษาโค้ด
* สามารถออกแบบหน้าจอได้อย่างอิสระ ไม่จำเป็นต้องยึดตามดีไซน์ใดเป็นพิเศษ โดยทีมงานจะเน้นประเมินคุณภาพของโค้ดและแนวทางการพัฒนาเป็นหลัก

## สิ่งที่ใช้ในการพิจารณา

ทีมงานจะพิจารณาจากหัวข้อหลัก ดังนี้

* โครงสร้างโปรเจกต์และการจัดระเบียบโค้ด
* คุณภาพและความอ่านง่ายของโค้ด
* การจัดการ State
* การจัดการ Loading, Error และ Empty State
* แนวคิดในการออกแบบที่อธิบายไว้ใน README

> **หมายเหตุ:** ความสวยงามของ UI ไม่ใช่ปัจจัยหลักในการประเมิน โดยให้ความสำคัญกับคุณภาพของโค้ดและแนวทางการออกแบบมากกว่า
